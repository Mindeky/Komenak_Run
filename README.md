KOMENAK RUN

This is a 2D game made entirely in python that is a lets call it a parody or just a silly game of my old elementary school
Your name is Shane a guy who goes through the worst school day he could ever imagine
Collect all the milks in each level, avoid the neverstoping enemies, pick up powerups to help to get through and prepera for the final boss
You have 3 lives so use them really carefully and i mean that because you dont want to die, you really don't

You just need to input this command: pip install pygame-ce
and i think thats it

Controls:
Arrow Keys: moving
P: pausing the game
Space: next level
Escape: quick exit (your gonna need this)

Power-ups:
Blue: shield
Lightblue: slows enemies
Orange: speed boost

if you want to you can change settings in the file by the same name
